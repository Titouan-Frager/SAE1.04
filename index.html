Bienvenue sur notre site

Nous avons réalisé ce site dans le cadre de notre projet scolaire sur la base de données KDou.

Présentation du travail

Le but de notre projet est d'étudier une base de données, de réaliser des requêtes SQL et d'utiliser les résultats pour proposer des améliorations à l'entreprise KDou.

Objectif du site

Ce site présente notre compte rendu collectif du projet KDou. Il rassemble les travaux réalisés, les requêtes SQL et les indicateurs étudiés par notre groupe. Il sert également de support à notre évaluation en programmation web, à travers la conception et la réalisation de ce site en HTML et CSS.
