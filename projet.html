Présentation du projet KDou

Dans le cadre de notre travail scolaire, nous avons étudié la base de données de l'entreprise KDou.

Cette base contient différentes informations qui peuvent être utilisées pour mieux comprendre le fonctionnement de l'entreprise et répondre à plusieurs problématiques.

Les objectifs

  • Découvrir l'organisation de la base de données.
  • Comprendre les relations entre les différentes tables.
  • Créer des requêtes SQL pour obtenir des informations précises.
  • Analyser les résultats obtenus.
  • Proposer des améliorations adaptées à KDou.

Déroulement du travail

Étape Description
1. Découverte Étude de la base et de ses différentes tables.
2. Requêtes Création de requêtes SQL pour répondre aux questions.
3. Analyse Observation et explication des résultats.
4. Indicateurs Calcul des indicateurs demandés à partir de la base de données.
